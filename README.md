# ระบบเว็บแอปพลิเคชันจัดเก็บข้อมูลและหลักฐานอ้างอิงสำหรับรายงานประเมินตนเองตามเกณฑ์ AUN-QA Version 4.0

ระบบได้รับการพัฒนาขึ้นอย่างสมบูรณ์ตามสถาปัตยกรรมระบบ (System Architecture), โครงสร้างฐานข้อมูล NoSQL / MongoDB (Hybrid Reference & Embedded Evidences), และโครงสร้างสิทธิ์การใช้งานตามแผนผังการออกแบบ

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

### 💻 Frontend
- **React.js** (Vite + React)
- **Tailwind CSS** สำหรับ Responsive UI และการออกแบบธีมตามมาตรฐาน
- **Lucide React** สำหรับไอคอนส่วนติดต่อผู้ใช้งาน
- **Axios** สำหรับการเรียก REST API พร้อม JWT Interceptor
- **React Router v6** สำหรับการจัดการเส้นทางและ Protected Routes ตามสิทธิ์

### ⚙️ Backend
- **Node.js + Express**
- **Mongoose ODM** (NoSQL / MongoDB)
- **JWT & Role-Based Access Control (RBAC)** Middleware
- **Multer** สำหรับการจัดการและบันทึกไฟล์อัปโหลด (เอกสารและรูปภาพ)
- **Automated Fallback In-Memory MongoDB Engine** ทำให้รันระบบได้ทันทีโดยไม่ต้องติดตั้ง MongoDB แยกต่างหาก หรือเชื่อมต่อ MongoDB จริงผ่านไฟล์ `.env` ได้อย่างสมบูรณ์

## 👥 บัญชีผู้ใช้งานเริ่มต้นสำหรับทดสอบระบบ (Seed Accounts)

| บทบาท (Role) | Username | Password | ความรับผิดชอบตามแผนผัง |
| :--- | :--- | :--- | :--- |
| **อาจารย์ในสาขาเทคโนโลยีคอมพิวเตอร์** | `lecturer` | `lecturer123` | บันทึกข้อมูลรายงาน SAR, แนบหลักฐาน 4 ประเภท (ไฟล์, รูป, ข้อความ, ลิงก์), ส่งตรวจ, แก้ไขหลักฐานใหม่เมื่อถูกส่งกลับ |
| **ผู้รับผิดชอบ AUN-QA** | `reviewer` | `reviewer123` | ตรวจสอบข้อมูลและหลักฐาน, ให้ความเห็น, ยืนยันสถานะบันทึก (Confirm), ส่งกลับเพื่อแก้ไข (Return), ติดตามความคืบหน้าภาพรวม |
| **ผู้ดูแลระบบ (Admin)** | `admin` | `admin123` | จัดการผู้ใช้งาน, รีเซ็ตรหัสผ่าน, จัดการสิทธิ์ (RBAC), เพิ่มหลักสูตร/สาขา, แก้ไขเกณฑ์แต่ละปีการศึกษา, ตรวจสอบจัดการไฟล์, ดู Logs ระบบ |

## 🚀 วิธีการรันระบบ

### วิธีที่ 1: ดับเบิลคลิกไฟล์ `start.bat` (สะดวกที่สุด)
เพียงดับเบิลคลิกที่ไฟล์ `start.bat` ในโฟลเดอร์หลัก ระบบจะเปิดหน้าต่างรันทั้ง Backend และ Frontend ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal แยกคำสั่ง

1. **เปิด Backend Server (Port 5000):**
```bash
cd server
npm start
```

2. **เปิด Frontend Client (Port 3000):**
```bash
cd client
npm run dev
```

เปิดเว็บเบราว์เซอร์ไปที่: **`http://localhost:3000`**

## 🗄️ โครงสร้างฐานข้อมูล (Collections ตามแผนผัง MongoDB)

1. `departments` - จัดเก็บสาขาวิชา (เช่น สาขาเทคโนโลยีคอมพิวเตอร์)
2. `courses` - จัดเก็บหลักสูตร
3. `criteria` - จัดเก็บเกณฑ์ AUN-QA Version 4.0 แยกตามปีการศึกษาและหลักสูตร
4. `roles` - จัดเก็บบทบาทผู้ใช้
5. `permissions` - จัดเก็บสิทธิ์การใช้งานระบบ
6. `users` - จัดเก็บข้อมูลผู้ใช้งานและรหัสผ่านที่เข้ารหัส bcrypt
7. `aunqa_records` - จัดเก็บบันทึกข้อมูลการประเมินตนเอง สถานะ (`draft`, `submitted`, `returned`, `confirmed`), ประวัติการตรวจ (`review_history`), และหลักฐานอ้างอิงแบบ Embedded (`evidences`)
8. `files` - จัดเก็บข้อมูลไฟล์หลักฐานและ metadata (ขนาด, ประเภท, ผู้ที่อัปโหลด)
9. `system_logs` - จัดเก็บบันทึกประวัติการกระทำของผู้ใช้งาน (Audit Trail)
